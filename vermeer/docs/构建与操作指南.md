# 本地构建和查验

桌面 `内核开发` 是工程入口，源码/补丁/证据由 Git 管理。Linux 大目录在 WSL Ubuntu 的 `/home/administrator/vermeer-build`；这避免 NTFS 对 Linux 大小写/符号链接语义的影响。不是云端任务，没有配置聊天结束后自动续跑的机制。

当前源码目录：`common` 为 g6f2f96be86b9 历史参考，`current-ack` 为新报告 g362d545d31a5 的干净 ACK worktree。后者尚缺原 CI 的 KSU/SUSFS/BBR3 等附加 patch，不能直接复刻当前自定义内核。

## 构建

Windows 在项目目录运行 `./build.ps1`，会调用 WSL 的 `scripts/build-baseline.sh`。新机器先在 Linux 执行 `bash scripts/bootstrap.sh` 拉取锁定源码/Clang；主机包依赖与版本见 `evidence/build-dependencies.txt`。无 sudo 自动安装/升级隐藏动作。

脚本首先核验干净源码与完整 commit，使用 Clang r450784e、ARCH=arm64、LLVM=1、原 Image 提取配置、原 full LTO/CFI/MODVERSIONS，并生成 KMI whitelist。为区别实验产物，LOCALVERSION 含 `-vermeer-baseline-lab`；文件路径与宿主工具引起的 config 差异保存在 `evidence/baseline-config-diff.json`。SOURCE_DATE_EPOCH 与编译用户/主机固定，默认 -j2 控制本机资源。

本树有原生 Linux Makefile，因此该命令是有效的原始源码编译检查；没有宣称它等于 Google 完整 hermetic release 构建，也没有假定 Kleaf 已跑过。原始 build.config、完整 ABI XML 与 KMI lists 留在源码里。主机 GCC/openssl/pahole 等已锁定记录，但 apt 包仓库长期可用性、自动生成模块签名密钥、不同工作路径造成的可复现性仍需要验证。未完成第二次干净逐字节对照前不得标记“可复现构建通过”。

输出日志在 evidence，Image/vmlinux/Module.symvers 在 build 或 WSL out 目录。它们即使成功也只能是非部署研究产物。不要把 Image 更名 boot.img，不执行网上的“关闭验证后刷入”建议。

## 测试和源码检查

```
bash scripts/test.sh
python scripts/kernel_audit.py image <镜像副本>
python scripts/kernel_audit.py module <模块副本.ko> --symvers <Module.symvers> --vermagic '<完整预期值>'
python scripts/analyze_ab.py <真实配对测试.csv>
```

Linux 测试依赖 gcc 和 Python 标准库，VAS C core 会在独立临时目录编译。日志包括测试数量、失败和跳过情况；模拟数据始终标记 synthetic。手机只读采集脚本和 TWRP NOOP 的能力见 BootGuard 文档。

参考内核完整构建成功后，可运行 `bash scripts/build-root-lkm.sh` 独立编译锁定 SukiSU。编译脚本不安装模块、不修改 boot/init_boot、不调用 adb/fastboot。主线 KPM 和 SUSFS 在该实验中关闭；若想切换 builtin/合并完整 SUSFS，必须先解决当前 Root 与源码证据问题。

## 资料补齐优先级

1. 当前运行内核的原始 uname/proc version 与当前 boot 分区哈希，并标注采集时间；最好提供对应镜像副本。
2. 当前五启动分区备份、大小、哈希以及 BootGuard 原有脚本/检测报告。
3. 当前 system_dlkm/vendor_dlkm 全部模块与 modules.load/dep、boot/vendor_boot 中模块、运行时 /proc/modules。
4. 当前第三方内核的具体下载链接、release/tag、Actions run、构建输入、patch commits/哈希和 manager/ksud 版本。
5. BootControl 状态读数与厂商支持的 retry/mark-success 时机证据、当前 snapshot merge 状态；不会要求破坏系统验证。

不需要为提供资料而自行刷机、切槽、重装 Root 或关闭安全保护。原始备份保持不变。
