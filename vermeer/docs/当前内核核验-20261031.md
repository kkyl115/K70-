## NoActive / ReKernel-X 的作用及安排

ReKernel-X 向配套用户态提供冻结进程的 Binder、信号和受监控 UID 网络事件，供其决定解冻等动作。它本身不是一个完整的 CPU 调度器或自动省电策略。NoActive 官方列出了多种可选内核后端；当前已选用的配套后端应先验证，不另加同用途的 LKM/KPM/eBPF 通知后端。[ReKernel-X 说明](https://github.com/myflavor/ReKernel-X)、[NoActive 官方开始使用](https://app.myflv.cn/guide/start.html)

已保存相关上游 `myflavor/ReKernel-X@8c217319d7d73c40667650a43a485e9f185e3a92` 的 README、GPL-2.0 许可、提交与 1.6 发布元数据。该仓库文档说明的是相关实现，**尚未证明它就是截图中 Nep-Timeline/lzghzr/myflavor 的 1.6-20261010 KPM 二进制来源**；没有取得该 KPM 原文件与构建输入，不宣称完成代码安全审计。

这次不推荐额外 KPM。现有用途明确，优先测这套组合：锁屏消息/来电通知、后台音乐/导航、分享与图片选择器、支付返回、应用切回、长时间待机。测试记录 NoActive 版本/模式、白名单、后端版本与实际冻结状态。当前白名单保持原状；出现问题时一次调整一项，恢复上一次记录的设置，不通过叠加第二个冻结器解决。

| 5，按使用场景 | NTSync | 仅针对使用该接口的 Wine/Winlator 等 Windows 兼容环境；已有 5.15 对象编译通过，下一门禁是匹配源码上的完整链接、上游并发 selftests、设备节点最小权限和用户态确实调用。不是 Android 原生游戏通用加速 |
| 6，独立研究 | BBRv3、DroidSpaces | BBRv3 对照 Cubic 测 TCP 发送吞吐/RTT/公平性，不承诺 UDP 游戏降延迟；DroidSpaces 要补必要 namespace/IPC 配置并审查 KABI 保留位和 SUSFS 冲突，不并入当前日用组合 |

VAS 的“解冻观察”只记录解冻后可运行的任务，不主动唤醒 NoActive 冻结的应用，也不把冻结时间算成 runnable 调度延迟。A710/A715 按真实 MIDR/容量分别记录；CPU 身份伪装若已启用，应在证据中注明，不能用被改写的可见信息直接标定硬件。

来源：[NTSync 内核接口](https://docs.kernel.org/userspace-api/ntsync.html)、[ZRAM 统计](https://docs.kernel.org/admin-guide/blockdev/zram.html)、[Google BBRv3](https://github.com/google/bbr/blob/v3/README.md)、[DroidSpaces 配置要求](https://www.droidspaces.org/docs/kernel-configuration.html)。没有实测百分比收益。

16 GiB ZRAM 是逻辑容量，不是预先扣走 16 GiB 物理 RAM。Scene 中约 3.5 GiB 已用 swap 也不等于压缩后的物理占用。用 `mm_stat` 的 orig_data_size、compr_data_size、mem_used_total 区分原始数据、压缩载荷和分配器占用；本次新增 `scripts/analyze-zram.py` 作离线计算。

## 安装脚本审查与运行方法

ZIP 将所有内容放在 `SukiSU_kernel-android13-5.15-178-AnyKernel3/` 下，没有根目录的 `META-INF/com/google/android/update-binary`。它不是标准 Recovery 直接安装布局；本工程不会自动重打包后交给手机。

`anykernel.sh` 明确 `do.devicecheck=0`、`do.check_boot_version=0`，`block=boot`、`is_slot_device=auto`，没有显式保护 A 槽。核心脚本通常按当前槽位工作，在特定 postinstall 条件下可能选择 inactive；不能描述为固定只写 B。`patch_vbmeta_flag=auto` 不是 AVB 验证通过证据。包中也不包含目标完整 vendor/system_dlkm、DTB、当前 vendor ramdisk，无法完成全 ABI 或 Boot Header 组合验收。内置工具均未执行。

电脑离线复核（不刷机）：

```powershell
python scripts/audit-anykernel.py 'C:\Users\Administrator\Downloads\SukiSU_kernel-android13-5.15-178-AnyKernel3 (1).zip'
python scripts/audit-features.py configs/baseline/received-20261031-g362d.config
```

`bootguard/preflight/collect-readonly.sh` 已补充活动 LSM、ZRAM、MGLRU、DAMON、TCP 与 CPUFreq 只读数据项，仅供机主自行选择运行；本工程没有下发到手机。输出分享前仍需检查隐私。已有历史备份不能因本报告而删除或覆盖。
