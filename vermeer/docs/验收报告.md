## 已处理的真实问题

1. Ubuntu 依赖安装中 libxml2 包名不可用，调整为该发行版有效依赖，保存首次错误及重试日志。
2. full LTO 出现严重主机资源压力与构建会话中断。保留两次日志；早期 shell 曾给出不可信 0 状态，已隔离为 unreliable-shell-exit，不用于成功判断。构建脚本改为显式 BUILD_COMPLETE。
3. 增加项目专用临时 swap、systemd 内存限制以继续完整 full LTO/CFI；没有为了编译而关闭 CFI/温控/模块版本检查，也没有关闭其他用户服务。限制只针对本工程任务。
4. Root 对象编译第一次缺少 flask.h。根因是 modules_prepare 不生成 SELinux 私有头；在独立输出目录构建 security/selinux 后，重编 kernelsu.o 成功。首次日志与修复后日志均保留。
5. SUSFS 修上下文时出现一次 CRLF 问题，生成器已固定 LF；后续仍存在真实 VMA padding 差异，明确保留失败状态。
