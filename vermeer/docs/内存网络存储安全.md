# 保留原厂能力优先的功能调查

依据是已独立提取的历史 5.15.178 config；后续上传的当前配置另存，不能混称同一内核。配置存在不证明该功能当前启用，也不证明厂商模块可加载。

| 功能 | 历史配置/源码结论 | 本次策略 |
|---|---|---|
| MGLRU | CONFIG_LRU_GEN=y，LRU_GEN_ENABLED=n | 已有源码，默认运行状态仍需 sysfs；不重复补丁或强开 |
| PSI | y | 保留；用于压力与延迟测量 |
| ZRAM / zsmalloc | m | 须验证 system/vendor_dlkm 实际模块、CRC、加载顺序 |
| 压缩 | 默认 lzo-rle；LZ4/ZSTD 代码存在 | 不凭名称换默认，先测压缩率/CPU 时间/换页尾延迟/能耗 |
| LZ4KD | 没有目标兼容验证 | 不启用 |
| ZRAM Writeback | n | 保持关闭；需写入预算、存储寿命和退化测试 |
| LMKD | 用户空间与 PSI 协同 | 不修改 HyperOS 阈值；需要 reload/kill/PSI 记录 |
| BBR / fq | ACK 有源码，历史配置未启用高级拥塞选择 | 仅提供 opt-in research fragment，保留 cubic 默认；未合并 |
| F2FS | 已启用及压缩支持 | 保留；不盲目回移文件系统补丁 |
| fs-verity | 已启用 | 保留，签名语义不变 |
| eBPF | 已有 syscall/JIT/BTF 配置 | 保留权限边界，不扩大非特权接口 |
| CFI | Clang14 CFI + full LTO | 保留；不把 KCFI 新实现混入旧工具链 |
| I/O scheduler | 需设备 UFS/队列运行信息 | 不预设 none/mq-deadline/BFQ 优劣 |

研究配置和策略在 `patches/memory/policy.json`、`patches/networking/bbr-research.config`、`patches/security/policy.json`。它们不是“已验证优化补丁”。新报告配置已经含 BBR3 等功能，若确认当前确为该内核，应先取得原补丁集，不能再重复叠加 BBR3。

内存实验用真实应用切换/游戏后台驻留/压力场景，固定 ZRAM 容量与负载，比较 PSI some/full、pgscan/pgsteal、workingset_refault、压缩比、swap IO 延迟、LMKD 杀进程数、应用重载与能耗。网络实验控制 RTT/带宽/损耗与服务器，比较吞吐、RTT p95、公平性和功耗；不得用公网波动的一次测速下结论。存储实验只使用专用测试文件，禁止在真实数据卷制造崩溃/断电。所有实验先离线或授权测试环境，不自动执行到手机。

Linux LTS/安全修复应按目标分支挑选并逐步验证，而不是把版本号升高当作安全认证。本次未声明完成 CVE 全量审计。GPU 电压/频率表、厂商温控、sched_ext、EEVDF 均未修改。
