# E｜签名伪装（signature spoofing）路线分析

日期：2026-10-27
一句话：签名伪装是 **framework 层**的事，与内核无关；这台设备两条路都可行，推荐「运行时 hook」路线。

## 一、现状侦察结果（2026-10-27 实测）

| 项 | 结果 |
|----|------|
| 内核方案 | KernelSU 3.3.1 (uapi: 5) |
| Zygisk | **无**（/data/adb/ksu 无 zygisk，modules 目录为空） |
| LSPosed | **未安装**（/data/adb/lspd 不存在） |
| microG / FakeGApps | **无痕迹** |
| getprop spoof/signature | **无任何项** |
| services.jar | **已 deodex**：含 classes.dex~classes4.dex（4 个 dex，共约 34MB） |
| services.odex/vdex | 存在（/system/framework/oat/arm64/，9.1MB + 416KB，缓存性质） |
| ROM | HyperOS OS3.0.302（Android 13，Redmi K70/vermeer） |
| 相关组件 | 存在 susfs4ksu、tricky_store、VerifiedBootHash、verified_modules |

### 关键判断
1. **「签名伪装内核」不存在**——签名伪装本质是让系统在检查 App 签名时「放行」，改的是 `PackageManagerService`（framework 层），不是内核。
2. **services.jar 已 deodex** → 理论上可以做「改 dex 直接 patch」（路线2），不必先 deodex（deodex 是最难一步，这里省掉了）。
3. **无 Zygisk、无 LSPosed** → 走运行时 hook（路线1）需先补装。

## 二、三条路线对比

### 路线1：ZygiskNext + LSPosed + FakeGApps（推荐）
- 原理：Zygisk 注入 zygote → LSPosed 运行时 hook 签名校验 → FakeGApps 模块给指定 App（microG）放行签名。
- 需要刷入（均为 KernelSU 模块）：
  1. ZygiskNext（给 KernelSU 提供 Zygisk）
  2. LSPosed-Zygisk 版
  3. FakeGApps（或等效 spoofing 模块）
- 优点：**不改 system 分区**、可随时卸载、风险低、可逆。
- 缺点：依赖三方模块兼容性（需匹配 Android 13 + HyperOS + KSU 3.3.1）。

### 路线2：直接 patch services.jar（deodex patch）
- 原理：baksmali 反汇编 services.jar 的 `PackageManagerService` → 修改签名校验逻辑 → smali 重打包 → 替换 jar → 清 oat/vdex 缓存 → 重启。
- 优点：原生 spoofing，不依赖 Zygisk/LSPosed。
- 缺点（本机风险高）：
  - 要改 `/system/framework/services.jar`（system 分区），且需删对应 oat 缓存。
  - 本机有 `VerifiedBootHash` + `verified_modules` + AVB，改 system 可能破坏完整性，**触发开不了机**（除非已关 verity）。
  - HyperOS 完整性/隐藏检测强，掉指纹、银行 App 风险大。

### 路线3：microG 官方
- 本质仍需先获得 spoofing 能力（即路线1或2），microG 本身只是 GmsCore 替代品，不是 spoofing 工具。

## 三、结论与建议

| 需求 | 推荐 | 理由 |
|------|------|------|
| 只想要签名伪装能力 | **路线1** | 不动 system、可逆、风险最低 |
| 想要 microG 去 Google | 路线1 + microG | 先有 spoofing，再装 microG GmsCore |
| 极致原生（不装框架） | 路线2 | 风险高，非必要不碰 |

### 前置风险提示（路线1 也必须知道）
- 装 ZygiskNext + LSPosed 后，部分银行/支付/游戏检测会变强，需配合现有 tricky_store/susfs 继续隐藏。
- 需确认 KernelSU 3.3.1 与目标 ZygiskNext/LSPosed 版本的兼容性（下载时核对适配 Android 13 / KSU uapi 5）。
